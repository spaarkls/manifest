# manifest

## Описание.
Утилита генерации манифеста каталога (список пар из имён файлов и их хеш-суммы) в стиле UNIX-утилит.
Пример вывода
`<DIR_NAME>: <MESSAGE_DIGEST>`

## Запуск программы.

```bash
make
```
Появится исполняемый файл `mangen`
Пример запуска:
```bash
./mangen tests/test_dir/ #или любая ваша директория
```

Запуск тестов:
```bash
make test
```
Запуститься скрипт `check.sh`

## Поддержка флагов
Общий шаблон запуска утилиты:

`./mangen [DIR_PATH] [OPTIONS]`
где, [OPTIONS] это ключ

```bash
./mangen -h 
```
`-h` выведет пример использования данной утилиты
`-v` отображает версию данной утилиты и информацию об авторе
`-e` данный ключ используется для игнорирования имени файла, ниже пример

```bash
./mangen tests/test_dir -e dir1
```
В этом случае все файлы/директории с именем dir1 будут игнорироваться
